# NexShip Technologies - Logistics Aggregator Website

Welcome to the official repository of **NexShip Technologies**, a modern logistics aggregator platform designed to simplify and streamline shipping solutions for businesses of all sizes.

## 🚀 Project Overview

This is a fully responsive React-based website for **NexShip Technologies**, built to showcase the company’s offerings, features, and value proposition to its target audience. The platform serves as an informative and conversion-focused website for businesses seeking efficient shipping and courier aggregation solutions.

## 🛠️ Tech Stack

- **React.js** (with functional components and hooks)
- **React Router** for navigation
- **Redux**
- **Axios** for API calls
- **Tailwind CSS** / **Custom CSS** for styling
- **Font Awesome** / **React Icons** for iconography
- **FormBuilder** 
- **ApexCharts** 
- **React Bootstrap**
